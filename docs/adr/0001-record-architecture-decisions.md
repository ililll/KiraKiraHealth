# ADR-0001: アーキテクチャ決定を ADR で記録する

- ステータス: 承認
- 日付: 2026-11-25

## コンテキスト

アジャイル開発では設計判断が段階的に行われるため、「なぜその選択をしたか」が失われやすい。

## 決定

重要な技術的判断は `docs/adr/` に連番の Markdown ファイルとして記録する。
テンプレートは [0000-template.md](0000-template.md) を使用する。

## 結果・影響

- 新メンバーが過去の判断理由を追えるようになる
- 判断を見直す際の前提が明確になる
- 次に記録すべき ADR の候補: 技術スタック（フロントエンド / バックエンド / DB）、クラウド基盤、認証方式、マルチテナント方式
