# Definition of Done（完了の定義）

ストーリーを「完了」とするには、以下をすべて満たしていること。

## コード
- [ ] 受け入れ条件をすべて満たしている
- [ ] コードレビューで承認されている（1名以上）
- [ ] `main` にマージされている

## 品質
- [ ] 自動テスト（ユニット / 必要に応じて結合・E2E）が追加され、CI が通っている
- [ ] Lint / 型チェックのエラーがない
- [ ] 重大なセキュリティ上の懸念がない（シークレット・個人情報の混入なし）

## 運用
- [ ] ステージング環境で動作確認済み
- [ ] 必要なドキュメント（README / API 仕様 / ADR）が更新されている
- [ ] プロダクトオーナーが確認済み
